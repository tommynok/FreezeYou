Доступні команди

  • okff — OneKEY заморозка.
  • okuf — OneKEY розморозка.
  • ff — заморозка.
  • uf — розморозка.
  • es — увімкнути параметр: wifi (з 6.2), cd — мобільна передача даних (з 7.1), bluetooth (з 7.3).
  • ds — вимкнути параметр (ті самі значення та версії, що й у es).
  • st — показати спливаюче повідомлення (Toast).
  • sn (8.6+) — показати сповіщення в шторці.
  • sp — відкрити вказаний додаток.
  • su — відкрити додаток за Uri.
  • lg (7.2+) — записати в лог рядок рівня ERROR; зазвичай не потрібно.
  • ls (8.7+) — заблокувати екран.

Внутрішні змінні

Необов'язкові додаткові параметри.

  • [ppkgn] (7.4+) — пакет попереднього додатку. Тільки для тригерів «При виході з додатків» і «Коли відкриваються додатки». Перед використанням у реальному завданні перевірте значення через st [ppkgn], щоб не заморозити випадково не той додаток.
  • [cpkgn] (7.4+) — пакет поточного додатку. Для тригерів «Коли відкриваються додатки», «При виході з додатків», «При розморозці додатків», «При заморозці додатків». Так само спершу перевірте через st [cpkgn].

Приклади команд

okuf

  • okuf — виконати OneKEY розморозку негайно.
  • okuf -d 10 — із затримкою 10 сек.

ff

  • ff com.tencent.mobileqq — заморозити додаток з пакетом com.tencent.mobileqq (QQ).
  • ff com.tencent.mobileqq,@5oiR55qE5YiX6KGo — заморозити QQ і всі додатки з «Моєї підбірки» з alias 5oiR55qE5YiX6KGo.
  • ff com.tencent.mobileqq,com.tencent.mm — заморозити QQ і WeChat (com.tencent.mm).
  • ff com.tencent.mobileqq,com.tencent.mm,com.taobao.taobao — заморозити QQ, WeChat і Taobao.
  • ff -d 3600 com.tencent.mobileqq — заморозити QQ із затримкою 3600 сек.

uf

  • uf com.tencent.mobileqq — розморозити QQ.
  • uf com.tencent.mobileqq,com.tencent.mm — розморозити QQ і WeChat.
  • uf com.tencent.mobileqq,@5oiR55qE5YiX6KGo — розморозити QQ і всі додатки з «Моєї підбірки» з alias 5oiR55qE5YiX6KGo.
  • uf com.tencent.mobileqq,com.tencent.mm,com.taobao.taobao — розморозити QQ, WeChat і Taobao.

es

  • es wifi — увімкнути Wi-Fi.
  • es -d 20 wifi — увімкнути Wi-Fi із затримкою 20 сек.
  • es wifi,cd — увімкнути Wi-Fi і мобільну передачу даних.
  • es wifi;okuf;uf com.tencent.mobileqq — кілька команд через ;: увімкнути Wi-Fi, виконати OneKEY розморозку, розморозити QQ.

ds

  • ds wifi — вимкнути Wi-Fi.
  • ds cd — вимкнути мобільну передачу даних.
  • ds wifi;okff — вимкнути Wi-Fi і виконати OneKEY заморозку.
  • ds -d 15 wifi;okff — те саме із затримкою 15 сек.

st

  • st Це тестове повідомлення — показати Toast із вказаним текстом.

sn

  • sn Заголовок,Текст сповіщення — сповіщення в шторці: заголовок і текст через кому.

sp

  • sp com.tencent.mobileqq — відкрити QQ.
  • sp com.tencent.mobileqq,com.tencent.mm — відкрити QQ і WeChat.

lg

  • lg 10086 — записати в лог рядок ERROR зі значенням 10086.

Додаткові параметри тригерів

Загальні правила

  • Частина тригерів не приймає параметри — якщо щось вказано, воно ігнорується.
  • Частина тригерів приймає параметр, але необов'язково.
  • Частина тригерів вимагає параметр, інакше завдання не виконається.

Вимоги по тригерах

  • «При включенні екрану» / «При виключенні екрану» — параметрів поки немає.
  • «Коли відкриваються додатки» — до версії 7.0 обов'язковий пакет додатку; з 7.0 можна вказати пакет додатку або «Мою підбірку» (з 9.2). Якщо вказано пакет, відкриття цього додатку зазвичай скасовує ще не виконані завдання тригера «При виході з додатків» для того самого додатку.
  • «При виході з додатків» — можна вказати пакет додатку або «Мою підбірку» (з 9.2). Якщо вказано пакет, вихід з цього додатку зазвичай скасовує ще не виконані завдання тригера «Коли відкриваються додатки» для того самого додатку.
  • «При розморозці додатків» / «При заморозці додатків» — можна вказати пакет додатку; без нього спрацює для будь-якого додатку.

Що можна вказати

  • Пакет додатку, наприклад com.tencent.mobileqq.
  • «Моя підбірка», наприклад @5oiR55qE5YiX6KGo.

Приклади

  • Тригер «Коли відкриваються додатки», параметр com.tencent.mobileqq — завдання виконається при запуску QQ.
  • Той самий тригер, параметр com.tencent.mobileqq,com.tencent.mm — при запуску QQ або WeChat.
  • Той самий тригер, параметр com.tencent.mobileqq,@5oiR55qE5YiX6KGo — при запуску QQ або будь-якого додатку з «Моєї підбірки» з alias 5oiR55qE5YiX6KGo.
  • Той самий тригер, параметр — пакет поточного лаунчера — при поверненні на робочий стіл.
  • Тригер «При виході з додатків» без параметра — при виході з будь-якого додатку.
