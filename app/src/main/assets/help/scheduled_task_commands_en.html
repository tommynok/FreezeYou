Available commands

  • okff — Onekey Freeze.
  • okuf — Onekey Unfreeze.
  • ff — freeze.
  • uf — unfreeze.
  • es — enable a setting: wifi (6.2+), cd — mobile data (7.1+), bluetooth (7.3+).
  • ds — disable a setting (same values and versions as es).
  • st — show a Toast message.
  • sn (8.6+) — show a notification in the notification shade.
  • sp — open the specified app.
  • su — open an app via Uri.
  • lg (7.2+) — write an ERROR-level log line; not needed under normal use.
  • ls (8.7+) — lock the screen.

Internal variables

Optional additional parameters.

  • [ppkgn] (7.4+) — previous app's package name. Only for the "When Leave Applications" and "When Open Applications" triggers. Before relying on it in a real task, check its value with st [ppkgn] to reduce the risk of freezing the wrong app.
  • [cpkgn] (7.4+) — current app's package name. For the "When Open Applications", "When Leave Applications", "When Unfreeze Applications" and "When Freeze Applications" triggers. Check it first with st [cpkgn] as well.

Command examples

okuf

  • okuf — run Onekey Unfreeze immediately.
  • okuf -d 10 — with a 10-second delay.

ff

  • ff com.tencent.mobileqq — freeze the app with package com.tencent.mobileqq (QQ).
  • ff com.tencent.mobileqq,@5oiR55qE5YiX6KGo — freeze QQ and every app in the "My customization" list with alias 5oiR55qE5YiX6KGo.
  • ff com.tencent.mobileqq,com.tencent.mm — freeze QQ and WeChat (com.tencent.mm).
  • ff com.tencent.mobileqq,com.tencent.mm,com.taobao.taobao — freeze QQ, WeChat and Taobao.
  • ff -d 3600 com.tencent.mobileqq — freeze QQ with a 3600-second delay.

uf

  • uf com.tencent.mobileqq — unfreeze QQ.
  • uf com.tencent.mobileqq,com.tencent.mm — unfreeze QQ and WeChat.
  • uf com.tencent.mobileqq,@5oiR55qE5YiX6KGo — unfreeze QQ and every app in the "My customization" list with alias 5oiR55qE5YiX6KGo.
  • uf com.tencent.mobileqq,com.tencent.mm,com.taobao.taobao — unfreeze QQ, WeChat and Taobao.

es

  • es wifi — enable Wi-Fi.
  • es -d 20 wifi — enable Wi-Fi with a 20-second delay.
  • es wifi,cd — enable Wi-Fi and mobile data.
  • es wifi;okuf;uf com.tencent.mobileqq — multiple commands separated by ;: enable Wi-Fi, run Onekey Unfreeze, unfreeze QQ.

ds

  • ds wifi — disable Wi-Fi.
  • ds cd — disable mobile data.
  • ds wifi;okff — disable Wi-Fi and run Onekey Freeze.
  • ds -d 15 wifi;okff — same, with a 15-second delay.

st

  • st This is a test message — show a Toast with the given text.

sn

  • sn Title,Notification text — show a notification with a title and text, separated by a comma.

sp

  • sp com.tencent.mobileqq — open QQ.
  • sp com.tencent.mobileqq,com.tencent.mm — open QQ and WeChat.

lg

  • lg 10086 — write an ERROR log line with the value 10086.

Trigger additional parameters

General rules

  • Some triggers don't accept additional parameters — anything entered is ignored.
  • Some triggers accept an additional parameter, but it's optional.
  • Some triggers require a matching additional parameter, or the task won't run.

Requirements per trigger

  • "On Screen On" / "On Screen Off" — no additional parameters yet.
  • "When Open Applications" — up to version 7.0 a package name is required; from 7.0 you can supply a package name or "My customization" (9.2+). With a package name set, opening that app normally cancels any pending delayed tasks scheduled by "When Leave Applications" for the same app.
  • "When Leave Applications" — a package name or "My customization" (9.2+) can be supplied. With a package name set, leaving that app normally cancels any pending delayed tasks scheduled by "When Open Applications" for the same app.
  • "When Unfreeze Applications" / "When Freeze Applications" — a package name can be supplied; without one, it fires for any app.

What you can supply

  • A package name, e.g. com.tencent.mobileqq.
  • "My customization", e.g. @5oiR55qE5YiX6KGo.

Examples

  • Trigger "When Open Applications", parameter com.tencent.mobileqq — the task runs when QQ starts.
  • Same trigger, parameter com.tencent.mobileqq,com.tencent.mm — when QQ or WeChat starts.
  • Same trigger, parameter com.tencent.mobileqq,@5oiR55qE5YiX6KGo — when QQ or any app from the "My customization" list with alias 5oiR55qE5YiX6KGo starts.
  • Same trigger, parameter set to the current launcher's package — runs when returning to the home screen.
  • Trigger "When Leave Applications" with no parameter — runs when leaving any app.
