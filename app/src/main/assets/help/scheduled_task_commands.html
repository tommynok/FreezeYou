Доступные команды

  • okff — OneKEY заморозка.
  • okuf — OneKEY разморозка.
  • ff — заморозка.
  • uf — разморозка.
  • es — включить параметр: wifi (с 6.2), cd — мобильная передача данных (с 7.1), bluetooth (с 7.3).
  • ds — отключить параметр (те же значения и версии, что у es).
  • st — показать всплывающее уведомление (Toast).
  • sn (8.6+) — показать уведомление в шторке.
  • sp — открыть указанное приложение.
  • su — открыть приложение по Uri.
  • lg (7.2+) — записать в лог строку уровня ERROR; обычно не требуется.
  • ls (8.7+) — заблокировать экран.

Внутренние переменные

Необязательные дополнительные параметры.

  • [ppkgn] (7.4+) — пакет предыдущего приложения. Только для триггеров «Когда открываются приложения» и «При выходе из приложений». Перед использованием в реальной задаче проверьте значение через st [ppkgn], чтобы не заморозить случайно не то приложение.
  • [cpkgn] (7.4+) — пакет текущего приложения. Для триггеров «Когда открываются приложения», «При выходе из приложений», «При разморозке приложений», «При заморозке приложений». Так же сперва проверьте через st [cpkgn].

Примеры команд

okuf

  • okuf — выполнить OneKEY разморозку немедленно.
  • okuf -d 10 — с задержкой 10 сек.

ff

  • ff com.tencent.mobileqq — заморозить приложение с пакетом com.tencent.mobileqq (QQ).
  • ff com.tencent.mobileqq,@5oiR55qE5YiX6KGo — заморозить QQ и все приложения из «Моей подборки» с alias 5oiR55qE5YiX6KGo.
  • ff com.tencent.mobileqq,com.tencent.mm — заморозить QQ и WeChat (com.tencent.mm).
  • ff com.tencent.mobileqq,com.tencent.mm,com.taobao.taobao — заморозить QQ, WeChat и Taobao.
  • ff -d 3600 com.tencent.mobileqq — заморозить QQ с задержкой 3600 сек.

uf

  • uf com.tencent.mobileqq — разморозить QQ.
  • uf com.tencent.mobileqq,com.tencent.mm — разморозить QQ и WeChat.
  • uf com.tencent.mobileqq,@5oiR55qE5YiX6KGo — разморозить QQ и все приложения из «Моей подборки» с alias 5oiR55qE5YiX6KGo.
  • uf com.tencent.mobileqq,com.tencent.mm,com.taobao.taobao — разморозить QQ, WeChat и Taobao.

es

  • es wifi — включить Wi-Fi.
  • es -d 20 wifi — включить Wi-Fi с задержкой 20 сек.
  • es wifi,cd — включить Wi-Fi и мобильную передачу данных.
  • es wifi;okuf;uf com.tencent.mobileqq — несколько команд через ;: включить Wi-Fi, выполнить OneKEY разморозку, разморозить QQ.

ds

  • ds wifi — отключить Wi-Fi.
  • ds cd — отключить мобильную передачу данных.
  • ds wifi;okff — отключить Wi-Fi и выполнить OneKEY заморозку.
  • ds -d 15 wifi;okff — то же самое с задержкой 15 сек.

st

  • st Это тестовое уведомление — показать Toast с указанным текстом.

sn

  • sn Заголовок,Текст уведомления — уведомление в шторке: заголовок и текст через запятую.

sp

  • sp com.tencent.mobileqq — открыть QQ.
  • sp com.tencent.mobileqq,com.tencent.mm — открыть QQ и WeChat.

lg

  • lg 10086 — записать в лог ERROR-строку со значением 10086.

Дополнительные параметры триггеров

Общие правила

  • Часть триггеров не принимает параметры — если что-то указано, оно игнорируется.
  • Часть триггеров принимает параметр, но необязательно.
  • Часть триггеров требует параметр, иначе задача не выполнится.

Требования по триггерам

  • «При включении экрана» / «При выключении экрана» — параметров пока нет.
  • «Когда открываются приложения» — до версии 7.0 обязателен пакет приложения; с 7.0 можно указать пакет приложения или «Мою подборку» (с 9.2). При указанном пакете открытие приложения обычно отменяет ещё не выполненные задачи триггера «При выходе из приложений» для того же приложения.
  • «При выходе из приложений» — можно указать пакет приложения или «Мою подборку» (с 9.2). При указанном пакете выход из приложения обычно отменяет ещё не выполненные задачи триггера «Когда открываются приложения» для того же приложения.
  • «При разморозке приложений» / «При заморозке приложений» — можно указать пакет приложения; без него сработает для любого приложения.

Что можно указать

  • Пакет приложения, например com.tencent.mobileqq.
  • «Моя подборка», например @5oiR55qE5YiX6KGo.

Примеры

  • Триггер «Когда открываются приложения», параметр com.tencent.mobileqq — задача выполнится при запуске QQ.
  • Тот же триггер, параметр com.tencent.mobileqq,com.tencent.mm — при запуске QQ или WeChat.
  • Тот же триггер, параметр com.tencent.mobileqq,@5oiR55qE5YiX6KGo — при запуске QQ или любого приложения из «Моей подборки» с alias 5oiR55qE5YiX6KGo.
  • Тот же триггер, параметр — пакет текущего лаунчера — при возврате на рабочий стол.
  • Триггер «При выходе из приложений» без параметра — при выходе из любого приложения.
