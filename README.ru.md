## О приложении

FreezeYou отключает приложения, которые не должны работать в фоне, и включает их обратно при необходимости — вручную, с домашнего экрана, или автоматически по расписанию и системным событиям — чтобы снизить расход батареи и фоновый шум.

**Основные возможности:**

- Заморозка/разморозка приложений в любом режиме: Без-root (DPM / Profile Owner), Root, Системное приложение, Shizuku
- Списки OneKEY заморозки и разморозки, заморозка при выходе из приложения, заморозка при выключении экрана
- Запланированные задания по времени и триггерам: включение/выключение экрана, запуск/выход из приложения, заморозка/разморозка
- Ярлыки и виджеты на домашнем экране для заморозки, разморозки и запуска
- Списки и фильтры: замороженные, незамороженные, системные, пользовательские, свои группы
- Быстрое уведомление после разморозки, действия в один тап из него
- Бекап и восстановление настроек, списков, ярлыков и запланированных заданий

## Отличия от оригинала

### ✦ Добавлено

- **Лончер и ярлыки активити** — выберите любое активити любого приложения, запустите его сразу или создайте ярлык на домашний экран; неэкспортируемые активити включены (запуск с повышением прав через Root/Shizuku)
- **Фильтр «Работающие»** в главном списке, доступен в любом режиме
- **Офлайн-страница справки** по синтаксису команд запланированных заданий
- **Вторая плавающая кнопка** для действий мульти-выделения
- **Быстрое переключение список/сетка**
- **Серые значки** замороженных приложений
- **Переработанные настройки** — 13 разделов в трёх группах, отдельная опасная зона
- **Предупреждение** при массовой заморозке системно-критических пакетов

### ✦ Улучшено

- «Разморозка и запуск» достаёт и до неэкспортируемых активити (запуск с повышением прав через Root/Shizuku)
- Тема, язык и шаблон главного экрана применяются мгновенно, без перезапуска приложения
- Бекап и восстановление работают через файлы (сохранение в файл / восстановление из файла)
- Лог можно отправить куда угодно файлом

### ✦ Исправлено
- Пакетная заморозка/разморозка через Shizuku
- Принудительная остановка в режиме Shizuku (апстрим пытался запустить `su`, которого там нет)
- Заголовки экранов больше не остаются на языке системы, когда язык в приложении другой
